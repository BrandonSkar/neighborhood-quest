🗺️ Neighborhood Quest — Setup

Make the QR codes to tape around your neighborhood. Cut them out, laminate if you like, and place each one at its spot!

Tip: host the folder for free on GitHub Pages, Netlify Drop, or Cloudflare Pages, then paste that link above. Each code opens the map straight to its stop. (This page needs internet to draw the codes; the game itself works offline once loaded.)

Just testing at home? Open index.html and add a stop's code to the address — e.g. index.html?c=b7c218 — to simulate scanning it. (Tapping a pin only shows info; scanning is the only way to stamp.)
