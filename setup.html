🗺️ Neighborhood Quest — Setup

1. Print a sheet of blank stickers.  2. Tape one somewhere good.  3. Type its code in here, drop the pin and publish.  📊 Dashboard →

1. Print a sheet of stickers

Nine blank Neighborhood Quest stickers, three across, each with its own code. No place names — nothing is committed to a spot yet, so you can tape any one of them anywhere. The nine codes are all different from each other and from every card you've already published, so a new sticker can never clash with a live one. Cut them out, laminate if you like, and take them for a walk.

The sheet itself waits at the bottom of this page — printing sends the stickers and nothing else.

2. Stickers you've placed

Standing at a sticker you just taped up? Type the code printed on it, then tap 📍 Use my location, name the spot, pick a picture and add a question. One sticker at a time — publish whenever you like.

3. Publish

Off by default, so publishing only updates the cards and nobody loses progress. Tick it when you've moved to a whole new set of spots.

Publishing saves your cards to the game's database so every phone loads them next time it opens (online). The game still works offline after that.

Start over

Clears every scan, player and missing-sticker tally from the database and puts the hunt back to Season 1. Each phone notices the season changed next time it opens and clears its own stamps. This can't be undone.

Missing-sticker emails
